## Автотесты для ручек API для Stellar Burgers.

### Реализованные сценарии

Созданы автотесты на следующие эндпоинты:
1. Создание пользователя
2. Логин пользователя
3. Изменение данных пользователя
4. Создание заказа
5. Получение заказов конкретного пользователя

### Структура проекра

- `methods` - пакет, содержащий методы, разделенные по классам
- `tests` - пакет, содержащий тесты, разделенные по классам
- `data` - файл, содержащий данные
- `generator` - файл, содержащий функцию генерации

## Иснструкция по запуску:

### Установка зависимостей:

> pip install -r requirenments.txt

### Запуск автотестов:

> pytest -v

### Просмотр отчета по прогону html:

> allure serve allure_results
